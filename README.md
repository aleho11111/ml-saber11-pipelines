# Laboratorio uv + scikit-learn (Saber 11)

1. Instala uv y Python 3.12.
2. En la raiz de esta carpeta: `uv venv venv_ml --python 3.12`
3. Activa el entorno y ejecuta: `uv pip install -r requirements.txt`
4. Registra el kernel: `python -m ipykernel install --user --name venv_ml --display-name "Python (venv_ml)"`
5. Abre `notebooks/01_...ipynb` en VS Code, elige el kernel `Python (venv_ml)` y ejecuta todo.
6. Haz lo mismo con `notebooks/02_...ipynb`.

No incluyas la carpeta `venv_ml` en la entrega.
